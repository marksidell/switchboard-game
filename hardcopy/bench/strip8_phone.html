Station Board 3, Strip 8: Real Phone Line

Board 3 (0x22), strip 8 = parts 9nn, A32 channel 24, expander bit 7 (OFFHOOK_8 / RING_DET_8). Proposal: docs/real_phone.md Rev 1, option B · 2026-10-23. Strips 1–7 unchanged.

Before you start

  1. No game running. The audience speaker is already on the Digiface 33/34 (--monitor-ch 33), so A32 output 24 is free.
  2. Disconnect the old monitor cable from strip 8: on J106 MONITOR (AOUT±_8), or, if it went in that way, soldered to R910/R911's J2-side pads (J105 pins 1, 14; shield pin 2). Nothing may stay on A32 output 24.
  3. Phone wired across strip 8's line pair at the game box (J7B101 pins 7/8).
