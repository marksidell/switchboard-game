# control — ring generator and controller board

The board as built: the ring generator and the Olimex ESP32-POE-ISO that runs
`control/` (the firmware). Single flat sheet.

The board is the authority. `docs/ring_generator.md` follows it as of Rev 68, and its
§10 maps the document's part names to the references on this board. Named `ring` until
2026-09-28.
